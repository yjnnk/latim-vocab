# Gallico · De Bello Gallico

Dicionário latino–português de 1.045 lemas verbais, com 12.155 ocorrências nos oito livros.

Abra `dist/index.html` diretamente ou execute `python3 -m http.server 8765 --directory dist`.

Para reproduzir os dados: `python3 scripts/fetch_sources.py`, depois `python3 scripts/build_data.py` e `python3 scripts/verify_data.py`.

Fontes e versão fixada: `data/sources.json`. Traduções editáveis: `data/translations.tsv`. Os originais são baixados sob demanda e não são incluídos no Git. Critérios completos na seção “Sobre os dados” do site.

Dados: LASLA, Université de Liège / LiLa, CIRCSE, https://github.com/CIRCSE/LASLA, sob CC BY-NC-SA 4.0. As glosas e os infinitivos são uma camada editorial sem revisão filológica independente. Código: MIT.
